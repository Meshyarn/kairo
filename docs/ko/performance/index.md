# 성능

이 섹션은 성능 벤치마크, 최적화 전략, Kairo의 라우팅 및 실행 패턴의 실제 검증을 다룹니다.

## 주요 주제

- **[벤치마크 리포트](/ko/performance/benchmarks)** – 라우팅 vs. 풀 모델 전략의 실제 비교
- **[성능 기준(대표값)](/ko/performance/baselines)** – 레포 벤치마크 기반 지연/메모리 “실측 값”
- **[성능 & 신뢰성](/ko/concepts/performance-and-reliability)** – 고신호 진단 + 최신 튜닝 포인트

## 빠른 사실

- ✅ 대표 실행에서 **상위 모델 baseline과 성공률 동률**(둘 다 pass@1 100%)
- 💰 동일 스위트 기준 **~72% 비용 절감**(Mini+Kairo 라우팅)
- ⏱️ **~28% wall-time 오버헤드**(대신 더 저렴하고, 경우에 따라 느릴 수 있음)

## 측정되는 항목

| 지표 | 중요한 이유 |
|--------|---|
| **성공률** | 에이전트 루프의 연쇄 실패 방지 |
| **작업당 비용** | 비용 효율적인 확장 가능 |
| **실행 시간** | 실시간 피드백 루프에 영향 |
| **토큰 사용량** | 컨텍스트 효율성 측정 |
