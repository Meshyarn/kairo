# 빠른 시작

"빠른 첫 성공" 경로입니다: Kairo를 설치하고 MCP 호스트에 연결한 뒤 첫 호출을 성공시킨 후, 필요에 따라 기능을 점진적으로 활성화합니다.

## 핵심 빠른 시작 경로 (4단계)

| 단계 | 주제 | 시간 | 배울 내용 |
|------|------|------|----------|
| 0 | [Kairo 설치 + MCP 설정](/ko/quickstart/npm-install-and-setup) | 8분 | npm 설치, Claude/Cline/Cursor의 MCP 설정 |
| 1 | [기본값 고르기](/ko/quickstart/pick-your-defaults) | 5분 | 환경변수, 예산 프리셋 |
| 2 | [첫 호출](/ko/quickstart/first-calls) | 10분 | 기본 `task`, `manage` 호출 + 응답 |
| 3 | [안전한 쓰기 활성화](/ko/quickstart/enable-writes) | 15분 | Plan → Apply 워크플로우, `draftId`, 안전장치 |

**합계: 0부터 생산성까지 38분**
