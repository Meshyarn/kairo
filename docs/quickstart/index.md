# Quickstart

This section is the "fast path": get Kairo installed, connected to your MCP host, make a first successful call, then progressively enable deeper capabilities.

## Core quickstart path (4 steps)

| Step | Topic | Time | What you'll learn |
|------|-------|------|-------------------|
| 0 | [Install Kairo + Configure MCP](/quickstart/npm-install-and-setup) | 8 min | npm installation, MCP config for Claude/Cline/Cursor |
| 1 | [Pick your defaults](/quickstart/pick-your-defaults) | 5 min | Environment variables, preset budgets |
| 2 | [First calls](/quickstart/first-calls) | 10 min | Basic `task` and `manage` calls + responses |
| 3 | [Enable safe writes](/quickstart/enable-writes) | 15 min | Plan → Apply workflow, `draftId`, safety gates |

**Total: 38 minutes from zero to productive**
